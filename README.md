# 정책자금 한눈에 보기

소상공인·중소기업 정책자금(소진공·중진공)의 종류와 신청 조건을 비교하고, 내게 맞는 자금을 진단하고, 사업계획서 초안과 서류 양식을 내려받는 정적 웹 페이지입니다. 서버와 외부 라이브러리가 없어서 `index.html`을 브라우저로 열면 동작하고, GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

> **이 페이지의 양식과 초안은 공식 서식이 아니며, 개인이 정리한 신청 준비용 안내입니다.** 심사 결과를 보장하지 않습니다. 신청 전에 반드시 기관의 공고 원문과 안내를 확인하세요.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| 자금 목록 | 자금을 검색하고 기관·대상·자금군·자료 기준으로 거릅니다. 조건, 절차, 서류 체크리스트, 원문 링크를 보여 줍니다. |
| 내게 맞는 자금 | 업종, 상시근로자 수, 업력 등을 입력하면 자금별로 충족, 확인 필요, 해당 없음을 판정하고 이유를 보여 줍니다. |
| 사업계획서 초안 | 입력한 사실만으로 초안을 만듭니다. 비어 있는 항목은 【작성 필요】로 남기고, 절별 복사와 Word(.docx) 내려받기를 지원합니다. |
| 서류·양식 | 사업계획서, 자금집행계획표, 위임장, 자가진단표의 빈 양식과 작성예시(가상 데이터)를 내려받습니다. |
| 일정·문의 | 접수 현황(확인일 표시), 문의처, 공식 사이트, 불법 브로커 주의를 보여 줍니다. |

반응형(데스크톱·태블릿·모바일)이고 라이트·다크 테마를 지원합니다.

## 자료 기준과 한계

- 자금 정보는 소상공인시장진흥공단 제2026-576호, 중소벤처기업진흥공단 제2026-574호(2026.10.1) 공고를 기준으로 합니다. 이전 공고에만 있던 자금은 "이전 공고 기준"으로 표시하고, 값이 엇갈리는 항목은 어느 쪽도 고르지 않고 "확인 필요"로 표시합니다.
- 확인하지 못한 항목은 추정하지 않고 "미확인"으로 둡니다. 소진공 필요 서류의 전체 목록, 중진공 밸류체인안정화 자금의 한도·금리·기간이 그렇습니다.
- 자격 진단과 서류 체크리스트는 이전 정리본 기준의 1차 점검이라, 최신 공고에서 바뀐 요건은 자금 상세와 함께 확인해야 합니다.
- 금리는 분기별 기준금리에 가산금리를 더하는 구조라 실제 값은 기관 공지를 확인해야 합니다.
- 접수 현황은 확인한 날짜를 화면에 표시하며, 날짜가 지나면 며칠 전 자료인지 알려 줍니다.
- Word(.docx)와 한컴오피스에서 직접 열어 본 것은 아닙니다. LibreOffice와 python-docx로는 열림을 확인했습니다.

## 파일 구성

| 경로 | 설명 |
| --- | --- |
| `index.html`, `styles.css` | 마크업과 스타일 |
| `core.js`, `detail.js`, `list-view.js`, `finder-view.js`, `draft-view.js`, `docs-view.js`, `app.js` | 화면 스크립트(이 순서로 불러옴) |
| `lib/` | 자격 진단 규칙, 초안 작성, .docx 생성기 |
| `data/funds.js` | 자금 데이터 |
| `forms/` | 내려받는 양식 9개(docx 7, xlsx 2) |
| `fonts/` | Pretendard 서브셋과 라이선스 |

## 로컬에서 보기

`index.html`을 브라우저로 열거나, 이 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000/`을 엽니다.
